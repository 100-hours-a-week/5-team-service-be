# 채팅 메시지 생성

> DB: `messages.text_message` VARCHAR(300)
> 저장: `seed/content/messages_greeting.json`, `messages_discussion.json`, ...
> 총 목표: 6카테고리 합계 ~500개 (6회, 카테고리별 1회)

한 번에 카테고리 1개씩 생성.

## 규칙
- **300자 이내** (초과 시 DB INSERT 실패)
- 실제 채팅처럼 짧고 자연스럽게 (대부분 1~3문장)
- 이모티콘 가끔 사용 OK (😊 👍 😭 ㅋㅋ ㅎㅎ 등)

## 카테고리별 요청 계획

| 카테고리 | 코드 | 개수 | 설명 |
|---------|------|------|------|
| 인사/입장 | `greeting` | 60개 | 채팅방 처음 들어왔을 때 |
| 책 내용 토론 | `discussion` | 120개 | 책 내용/장면/인물 언급하며 대화 |
| 의견 동의/반대 | `opinion` | 120개 | 다른 사람 말에 반응 |
| 감상 공유 | `impression` | 100개 | 책 읽은 감정/깨달음 |
| 일상/잡담 | `casual` | 60개 | 책과 무관한 대화 |
| 퇴장 인사 | `farewell` | 40개 | 나갈 때 인사 |

## JSON 형식
```json
[
  {"id": 1, "category": "greeting", "textMessage": "안녕하세요! 처음 참여하는데 기대돼요 😊"},
  {"id": 2, "category": "greeting", "textMessage": "오 다들 일찍 오셨네요 ㅋㅋ"}
]
```

## 카테고리별 가이드

### greeting — 첫 입장, 인사
짧고 밝은 톤. "안녕하세요~", "반갑습니다!", "오늘 기대돼요", "저 처음인데 잘 부탁해요"
- 길이: 대부분 10~50자

### discussion — 책 내용 토론 (가장 중요)
**특정 책 제목 언급하지 않기.** "이 책", "이 부분", "후반부" 같은 일반 표현 사용.
- "저는 주인공의 선택이 이해가 안 됐어요"
- "후반부 반전은 진짜 소름이었어요"
- "저자가 말하는 핵심 논점이 좀 약한 것 같지 않아요?"
- "이 부분 읽으면서 진짜 많이 생각했어요"
- 길이: 30~200자

### opinion — 동의/반대 반응
다른 사람 의견에 대한 반응. 앞에 "@닉네임" 없이 순수 반응만.
- 동의: "완전 공감이요", "저도 그렇게 느꼈어요", "맞아요 그 부분!!"
- 반대: "저는 좀 다르게 봤는데요", "근데 그건 좀...", "반대 의견인데 들어주세요 ㅋ"
- 길이: 10~150자

### impression — 감상 공유
책에서 받은 감정이나 깨달음.
- "읽으면서 눈물 났어요 진짜", "내 인생책 등극", "밤새 읽었어요"
- "이 책 읽고 생각이 많아졌어요", "요즘 이 책 생각이 자꾸 나요"
- 길이: 20~200자

### casual — 일상 잡담
책과 무관한 가벼운 대화.
- "오늘 날씨 진짜 좋다", "점심 뭐 드셨어요?", "카페에서 읽고 있어요 ㅎㅎ"
- 길이: 10~80자

### farewell — 퇴장 인사
- "먼저 갈게요~ 다음에 또!", "오늘 재밌었어요 감사합니다", "다음 라운드도 기대!"
- 길이: 10~60자

## 주의사항
- 300자 초과 금지
- 같은 메시지 반복 없음
- **특정 책 제목/저자 언급 X** (build 스크립트에서 조합)
- 자연스러운 채팅 말투 유지
