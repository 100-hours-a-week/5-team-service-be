# 토론 주제 생성

> DB: `meeting_round_discussion_topics.topic` VARCHAR(120), NOT NULL
> 저장: `seed/content/topics_novel.json`, `topics_economy.json`, ...
> 총 목표: 8장르 × 40개 = 320개 (8회, 장르별 1회)

한 번에 장르 1개, 40개씩 생성.

## 규칙
- **120자 이내** (초과 시 DB INSERT 실패)
- **질문 형태** — 토론을 유도하는 개방형 질문
- Yes/No로만 답할 수 없는 질문으로

## 장르
`NOVEL`, `ECONOMY_BUSINESS`, `ESSAY`, `HUMANITIES_PHIL`, `SOCIETY_POLITICS`, `SELF_DEVELOPMENT`, `SCIENCE_TECH`, `HISTORY`

## JSON 형식
```json
[
  {"id": 1, "genre": "NOVEL", "topic": "주인공의 마지막 선택이 옳았다고 생각하나요? 다른 선택지가 있었을까요?"},
  {"id": 2, "genre": "NOVEL", "topic": "이 소설에서 가장 공감한 인물은 누구이고, 그 이유는?"}
]
```

## 장르별 질문 방향

| 장르 | 질문 방향 | 예시 |
|------|----------|------|
| NOVEL | 인물 심리, 결말, 작가 의도, 현실 비교 | "결말에 만족했나요? 어떤 결말을 원했나요?" |
| ECONOMY_BUSINESS | 이론의 현실 적용, 사례 비판, 실천 가능성 | "저자의 전략이 한국 시장에서도 통할까요?" |
| ESSAY | 글쓴이 관점 공감, 경험 공유, 가치관 토론 | "이 글에서 가장 공감한 부분과 그 이유는?" |
| HUMANITIES_PHIL | 철학 개념 적용, 윤리적 딜레마, 사고 실험 | "이 철학 개념이 일상에서 어떻게 나타나나요?" |
| SOCIETY_POLITICS | 사회 문제 해결책, 시각 차이, 현상 분석 | "이 문제의 근본 원인은 무엇이라고 보나요?" |
| SELF_DEVELOPMENT | 실천 가능성, 개인 적용, 조언 평가 | "이 책의 조언 중 실제로 실천해볼 것은?" |
| SCIENCE_TECH | 미래 영향, 양면성, 윤리적 고려 | "이 기술이 10년 후 우리 생활을 어떻게 바꿀까요?" |
| HISTORY | 역사 해석, 현재와 비교, 인물 평가 | "이 역사적 결정이 현대에도 반복될 수 있을까요?" |

## 톤
- 친근하되 생각을 자극하는 질문
- "~라고 생각하나요?", "~에 대해 어떻게 봐요?", "~한다면 어떨까요?" 같은 열린 형태
- **특정 책 제목 언급 X** — "이 책에서", "저자가" 같은 일반 표현 사용

## 주의사항
- 120자 초과 금지
- 40개 모두 다른 질문 (비슷한 질문 변형도 최소화)
- genre 값 정확히 사용
