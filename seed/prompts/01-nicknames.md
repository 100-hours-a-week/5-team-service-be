# 닉네임 생성

> DB: `users.nickname` VARCHAR(20), NOT NULL, UNIQUE
> 저장: `seed/content/nicknames.json`
> 총 목표: 500개 베이스 (build 스크립트에서 접미사 조합으로 5,000명까지 확장)

한 번에 100개씩 생성. 총 5회 요청 예정.

## 규칙
- **10자 이내** (접미사 `_123` 붙여도 20자 안 넘게)
- 한글만 (영문/숫자 불가)
- 띄어쓰기 없음
- 100개 내 중복 없음

## 스타일 비율

- **독서/문학 (40%)**: 책먹는하마, 밤독서가, 에세이중독, 소설의정원, 페이지터너, 서재지기, 활자중독
- **감성/자연 (30%)**: 달빛산책, 청포도, 새벽안개, 석양여행, 봄날오후, 바람의노래
- **일상/취미 (20%)**: 카페라떼, 고양이집사, 산책러, 음악듣는중, 라면매니아
- **유머/개성 (10%)**: 야근탈출, 만년초보, 칼퇴요정, 귀차니스트, 잠이보약

## JSON 형식
```json
[
  {"id": 1, "nickname": "책먹는하마"},
  {"id": 2, "nickname": "달빛산책"}
]
```
