# 사용자 자기소개 생성

> DB: `users.leader_intro` VARCHAR(300), `meeting_members.member_intro` VARCHAR(300)
> 저장: `seed/content/user_intros.json`
> 총 목표: 리더 150개 + 멤버 150개 (3회)

한 번에 리더 50개 + 멤버 50개 생성. 총 3회 요청 예정.

## 규칙
- **300자 이내** (한글 기준, 초과 절대 금지)
- 리더/멤버 배열 분리

## 리더 자기소개 — 모임을 왜 만들었는지

다양한 동기: 좋은 책을 나누고 싶어서, 혼자 읽으면 안 읽게 돼서, 사람들과 대화하고 싶어서, 전문 분야 깊이 파고 싶어서, 독서 습관 만들려고, 퇴근 후 뭔가 하고 싶어서 등

다양한 톤: 진지한 사람, 가벼운 사람, 유머러스한 사람, 내향적인 사람, 열정적인 사람

예시:
- "퇴근하고 넷플릭스만 보다가 이러면 안 되겠다 싶어서 모임 만들었어요. 같이 책 읽고 수다 떨 사람 구합니다."
- "경영학 전공인데 실무에서 쓸 수 있는 책들을 같이 읽고 토론하고 싶어요."

## 멤버 자기소개 — 왜 참여하고 싶은지

다양한 동기: 추천받은 책 읽고 싶어서, 다양한 관점 듣고 싶어서, 독서 동기부여 필요해서, 새로운 사람 만나고 싶어서, 이 장르 좋아해서 등

예시:
- "올해 목표가 30권 읽기인데 아직 2권... 강제성이 필요합니다 ㅋㅋ"
- "소설 좋아하는데 주변에 같이 얘기할 사람이 없어서 찾아왔어요!"

## JSON 형식
```json
{
  "leaderIntros": [
    {"id": 1, "content": "퇴근하고 넷플릭스만..."}
  ],
  "memberIntros": [
    {"id": 1, "content": "올해 목표가 30권..."}
  ]
}
```

## 주의사항
- 같은 구조 반복 금지 ("저는 ~하는 사람입니다. ~를 좋아합니다." 패턴 반복 X)
- 존댓말/반말 혼재 자연스럽게
- 300자 넘으면 DB INSERT 실패함 — **반드시 확인**
