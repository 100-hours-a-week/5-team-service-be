# 독후감 생성

> DB: `book_reports.content` TEXT, NOT NULL
> 저장: `seed/content/book_reports_novel.json`, `book_reports_economy.json`, ...
> 총 목표: 8장르 × 25개 = 200개 (8회, 장르별 1회)

한 번에 장르 1개, 25개씩 생성.

## 규칙
- **500~2,000자** 사이 (TEXT 타입이라 상한은 넉넉하지만, 너무 짧거나 길면 비현실적)
- 특정 책 제목/저자명/페이지 번호 언급하지 않기 (build 스크립트에서 실제 책과 매칭)
- "이 책", "저자", "이 부분", "후반부에서" 같은 일반적 표현 사용

## 장르
`NOVEL`, `ECONOMY_BUSINESS`, `ESSAY`, `HUMANITIES_PHIL`, `SOCIETY_POLITICS`, `SELF_DEVELOPMENT`, `SCIENCE_TECH`, `HISTORY`

## JSON 형식
```json
[
  {
    "id": 1,
    "genre": "NOVEL",
    "content": "이 소설을 읽으면서 가장 인상 깊었던 부분은..."
  }
]
```

## 장르별 가이드

| 장르 | 핵심 톤 | 자주 쓰는 표현 |
|------|---------|---------------|
| NOVEL | 감정, 장면 묘사, 인물 분석 | "~하는 장면에서", "주인공이 ~할 때" |
| ECONOMY_BUSINESS | 인사이트, 실천, 비판적 사고 | "이 개념을 적용해보면", "실무에서는" |
| ESSAY | 공감, 일상 연결, 문장 감상 | "나도 비슷한 경험이", "이 문장이 마음에" |
| HUMANITIES_PHIL | 사유, 질문, 관점 비교 | "이 논증을 따라가면", "새로운 관점" |
| SOCIETY_POLITICS | 현실 인식, 문제의식 | "우리 사회에서도", "이 데이터를 보면" |
| SELF_DEVELOPMENT | 실천 후기, 변화, 동기부여 | "한 달간 시도해봤는데", "가장 와닿은 조언은" |
| SCIENCE_TECH | 발견, 호기심, 미래 전망 | "이런 원리가 있다니", "기술이 발전하면" |
| HISTORY | 해석, 교훈, 현재와 연결 | "그 시대에는", "지금까지 영향을" |

## 톤 & 스타일
- 실제 20~30대가 쓸 법한 자연스러운 문체
- 같은 구조 반복 금지 ("첫째~둘째~셋째" 나열, "저는~입니다" 시작 반복 X)
- 25개가 전부 다른 느낌이어야 함 — 진지한 것, 가벼운 것, 감성적인 것, 비판적인 것 섞기
- 줄바꿈은 `\n`으로 표현
